## How to Write Good Predictions

Each prediction should be:
- **Concrete** — no vague outcomes. "X will happen" not "things might change"
- **Falsifiable** — it must be possible to clearly say yes or no
- **Time-bound** — when will this resolve? If it's open-ended, set a deadline
- **Independent** — avoid predictions that are subsets of each other

Confidence guide:
- 50–55%: coin flip, genuine uncertainty
- 60–70%: lean in one direction, but wouldn't be surprised either way
- 75–85%: fairly confident, would need strong counter-evidence to change mind
- 90%+: very confident — reserve for near-certainties
